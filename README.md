# Vamsikrishna Gollapudi — Portfolio

Personal portfolio for Azure DevOps & Site Reliability Engineering. Static site, no build step, served by GitHub Pages.

- `index.html` — content and structure
- `styles.css` — design tokens (dark/light), layout, components
- `main.js` — navigation, theme toggle, case-study modals, Architecture Lab diagrams, SRE Operations Lab simulation
- `Vamsikrishna_Gollapudi_Resume.pdf` — resume, shown view-only in the on-page viewer
- `pdf-viewer.js` / `pdf-viewer.css` — lazy-loaded PDF.js resume viewer

The SRE Operations Lab uses simulated, seeded data generated in the browser. It does not connect to any real service.
